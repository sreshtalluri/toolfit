# toolfit M3a Implementation Plan (Retry/Backoff, Badge, Packaging, Exit Codes)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the buildable-code half of M3's launch infrastructure — retry/backoff on the model adapters, a locally-generated SVG badge, verified-buildable PyPI packaging, and opt-in `--strict` exit codes for CI gating.

**Architecture:** A shared `_with_retry` helper wraps only the network-call line inside each adapter's `call_with_tools`. A new `report/badge.py` renders a self-contained SVG string from existing `ConfusionMatrix`/`MutationTrialResult` data — no new data model. `pyproject.toml` gets completed metadata, verified by an actual local build/install, not a pytest test. `cli.py` gains one `--strict` flag on each command, computed entirely from data the confusion matrix / lint findings already produce.

**Tech Stack:** Python 3.10+, `anthropic`, `openai`, `typer`, `pytest` + `pytest-asyncio`. No new dependencies — the badge is hand-rolled SVG text, not a rendering library.

**Spec:** `docs/designs/toolfit-v0-scope.md`, section "## M3a Design (added during M3 planning, 2026-08-28)". Also read "## M2 Design" for `ConfusionMatrix`/`MutationTrialResult`'s existing shape, which this plan reuses unchanged.

## Global Constraints

- **Retry only on rate limits, never on parsing failures.** `_with_retry` catches exactly `anthropic.RateLimitError`/`openai.RateLimitError` — nothing else. A malformed-JSON tool-call response (already handled elsewhere as a no-call miss) must never be retried.
- **Never silently swallow past the retry cap.** After `max_retries` is exhausted, the original exception re-raises. No fallback to a fake "no call" result on exhaustion — that would hide a real outage as if it were normal model behavior.
- **`sleep_fn` is injectable.** `_with_retry`'s tests must never actually sleep — pass a stub `sleep_fn` and assert on how it was called, not on wall-clock time.
- **The badge never requires M4's `--fix` loop.** `render_badge` takes an optional `MutationTrialResult` (already built in M2) — it must not reference anything from `fix/fixer.py`.
- **Badge integrity: no bare number.** Every badge must embed model-under-test, generator model, seed count, and a task-suite hash — never just a percentage with no traceable identity.
- **`--strict` is opt-in, default `False` on both commands.** Today's exit-0-always behavior must be unchanged when `--strict` is omitted — this plan must not alter any existing test's expected exit code.
- **No `twine upload` in this plan.** PyPI packaging work stops at "verified buildable via a local install," never an actual publish.
- **Reuse existing data structures unchanged.** `ConfusionMatrix`, `TrialRecord`, `MutationTrialResult` (all already built in M1/M2) must not be modified by this plan — every new component here reads them, never changes their shape.

```python
T = TypeVar("T")


def _with_retry(
    fn: Callable[[], T],
    *,
    max_retries: int = 3,
    base_delay: float = 1.0,
    sleep_fn: Callable[[float], None] = time.sleep,
) -> T:
    """Retry a network call on a rate-limit error only (design doc M3a Design §1) — never on a
    parsing failure, which retrying can't fix. Exponential backoff with jitter; re-raises after
    max_retries so a persistent outage is never silently swallowed. sleep_fn is injectable so
    tests run instantly instead of actually sleeping."""
    for attempt in range(max_retries + 1):
        try:
            return fn()
        except (anthropic.RateLimitError, openai.RateLimitError):
            if attempt == max_retries:
                raise
            delay = base_delay * (2**attempt) + random.uniform(0, base_delay)
            print(
                f"WARNING: rate limited, retrying in {delay:.1f}s (attempt {attempt + 1}/{max_retries})",
                file=sys.stderr,
            )
            sleep_fn(delay)
    raise AssertionError("unreachable")  # every iteration above returns or re-raises
```

```python
"""Locally-generated static SVG badge (design doc M3a Design §2) — no hosted badge service, the
user runs `eval --badge` and commits the SVG themselves (Constraints: no web UI). Every badge
embeds enough metadata (model, generator model, seeds, task-suite hash) that the bare percentage
can never be read without its benchmark identity — the integrity requirement from the design
doc's "What Makes This Cool" section.
"""

from __future__ import annotations

import hashlib

from toolfit.grade.confusion import ConfusionMatrix
from toolfit.grade.mutator import MutationTrialResult


def _task_suite_hash(matrix: ConfusionMatrix) -> str:
    pairs = sorted(
        (tool_name, trial.task.text) for tool_name, trials in matrix.trials_by_tool.items() for trial in trials
    )
    digest = hashlib.sha256(repr(pairs).encode("utf-8")).hexdigest()
    return digest[:8]


def _overall_pass_rate(matrix: ConfusionMatrix) -> float:
    all_trials = [trial for trials in matrix.trials_by_tool.values() for trial in trials]
    if not all_trials:
        return 0.0
    return sum(1 for t in all_trials if t.passed) / len(all_trials)


def render_badge(matrix: ConfusionMatrix, mutation_result: MutationTrialResult | None = None) -> str:
    if mutation_result is None:
        rate = _overall_pass_rate(matrix)
        label_text = f"toolfit: {rate:.0%}"
    else:
        before_rate = sum(mutation_result.before_passes) / len(mutation_result.before_passes)
        after_rate = sum(mutation_result.after_passes) / len(mutation_result.after_passes)
        label_text = f"toolfit: {before_rate:.0%} → {after_rate:.0%}"

    task_suite_hash = _task_suite_hash(matrix)
    metadata = (
        f"model={matrix.model} generator={matrix.generator_model} seeds={matrix.seeds} "
        f"task_suite={task_suite_hash}"
    )

    width = 20 + len(label_text) * 7
    return (
        f'<svg xmlns="http://www.w3.org/2000/svg" width="{width}" height="20" role="img" aria-label="{label_text}">\n'
        f"  <title>{label_text}</title>\n"
        f"  <desc>{metadata}</desc>\n"
        f'  <rect width="{width}" height="20" fill="#4c1" rx="3"/>\n'
        f'  <text x="10" y="14" font-family="sans-serif" font-size="11" fill="#fff">{label_text}</text>\n'
        "</svg>"
    )
```
